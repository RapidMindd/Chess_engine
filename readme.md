# Chess engine

Шахматный движок на C++14. Проект реализует представление позиции,
генерацию легальных ходов, оценочную функцию и поиск лучшего хода.

## Основные возможности

- Поиск лучшего хода через negamax.
- Alpha-beta отсечение для уменьшения числа перебираемых веток.
- Quiescence search на границе основной глубины, чтобы уменьшать эффект
  горизонта на тактических позициях.
- Расширение quiescence search при шахе: если сторона под шахом, движок
  перебирает все легальные ответы.
- Таблица транспозиций с типами записей `EXACT`, `LOWER_BOUND` и `UPPER_BOUND`.
- Zobrist hashing для быстрого ключа позиции.
- Инкрементальное обновление Zobrist hash при ходе.
- Move ordering перед поиском.
- Приоритет взятий, превращений и ходов, улучшающих piece-square table.
- Счетчики посещенных узлов основного поиска и quiescence search.
- Оценка мата с учетом глубины `ply`, чтобы движок предпочитал более быстрый
  мат.
- Комплексная оценочная функция: материал, мобильность, piece-square tables,
  пешечная структура и безопасность короля.
- Генерация активных ходов для quiescence search: взятия и превращения.
- Быстрая проверка атакованности клетки для фильтрации легальных ходов и
  проверки шаха.
- Выполнение и откат ходов через `makeMove` / `undoMove`, что позволяет
  эффективно перебирать дерево вариантов без постоянного пересоздания позиции.

## Правила шахмат

Генератор умеет строить:

- псевдолегальные ходы;
- легальные ходы с фильтрацией ходов, оставляющих своего короля под шахом;
- активные ходы для quiescence search: взятия и превращения;
- отдельные списки взятий для фигур;
- проверки атакованности клетки;
- быструю проверку атакованности клетки без генерации полного списка ходов;
- проверку шаха;
- проверку мата;
- проверку пата.

## Поиск

Движок использует:

- negamax;
- alpha-beta отсечение;
- quiescence search на глубине 0;
- расширение quiescence search при шахе;
- оценку мата с учетом `ply`, чтобы выбирать более быстрый мат;
- счетчики посещенных узлов:
  - `nnodes` для основного поиска;
  - `qnodes` для quiescence search;
- сортировку ходов перед поиском.

`Engine::findBestMove` возвращает лучший ход и оценку позиции в пешках.

## Упорядочивание ходов

Перед перебором ходов движок присваивает каждому ходу score:

- высокий приоритет взятиям;
- учитывается примерная ценность взятой и ходящей фигуры;
- высокий приоритет превращениям;
- учитывается изменение piece-square table для ходящей фигуры.

Во время поиска лучший по score ход из оставшихся переставляется в начало
текущего диапазона.

## Оценочная функция

Оценка позиции складывается из нескольких факторов:

- материал;
- мобильность фигур;
- piece-square tables;
- пешечная структура;
- безопасность короля.

Материальные веса:

- пешка: 100;
- конь: 320;
- слон: 330;
- ладья: 500;
- ферзь: 900;
- король: 0.

Мобильность учитывается для ферзя, коня, слона и ладьи. Piece-square tables
используются для короля, ферзя, коня, слона и пешки. Для черных фигур таблицы
отзеркаливаются.

Пешечная структура штрафует сдвоенные пешки, особенно если рядом нет пешек на
соседних вертикалях. Безопасность короля дает небольшой бонус за пешечное
прикрытие рокированного короля.

## Transposition table и Zobrist hashing

В проекте есть таблица транспозиций:

- фиксированный массив `TTEntry`;
- размер по умолчанию: `1ULL << 22`;
- индексирование через `key & (size - 1)`;
- типы записей:
  - `EXACT`;
  - `LOWER_BOUND`;
  - `UPPER_BOUND`;
- хранение ключа, оценки, глубины и типа записи.

Zobrist hashing учитывает:

- расположение фигур;
- сторону хода;
- права на рокировку;
- поле en passant.

Также реализовано инкрементальное обновление Zobrist hash для обычных ходов,
взятий, en passant, превращений и рокировки.

## Нотация ходов

Ввод и базовый вывод ходов используют формат:

```text
e2-e4
```

Для self-play дополнительно есть вывод ходов в шахматной нотации через
`printMove`, включая:

- рокировку `0-0` и `0-0-0`;
- взятия;
- превращения;
- шах `+`;
- мат `#`.

## Приложения

В папке `apps` находятся три исполняемых сценария:

- `main.cpp` - интерактивная игра из начальной позиции. Пользователь вводит ход,
  движок отвечает ходом на глубине 6.
- `selfplay.cpp` - партия движка против самого себя. Глубина по умолчанию 7,
  ее можно передать аргументом.
- `speed-bench.cpp` - простой benchmark на нескольких FEN-позициях. Показывает
  найденные ходы, время, NPS, число negamax-узлов и quiescence-узлов.

## Сборка и запуск

Сборка основного приложения:

```bash
make
```

Запуск интерактивной игры:

```bash
make run
```

Запуск тестов:

```bash
make test
```

Запуск benchmark:

```bash
make bench
```

Можно передать глубину через `ARGS`:

```bash
make bench ARGS=5
make selfplay ARGS=6
```

Очистка артефактов сборки:

```bash
make clean
```

## Тесты

Тесты написаны на Boost.Test и покрывают:

- конструкторы и очистку позиции;
- начальную позицию;
- выполнение и откат ходов;
- FEN-инициализацию;
- генерацию ходов всех фигур;
- ходы и взятия пешек;
- превращения;
- en passant;
- псевдолегальные и легальные ходы;
- запрет нелегальных ходов при шахе;
- рокировку и откат рокировки;
- мат и пат;
- поиск мата в 1 ход;
- выбор более быстрого мата.

## Структура проекта

```text
src/
  engine.*               поиск лучшего хода
  evaluator.*            оценочная функция
  move.*                 структура хода и массив ходов
  move_generator.*       генерация ходов и проверки шаха/мата/пата
  piece.*                типы фигур и конвертация фигура <-> символ
  position.*             позиция, FEN, make/undo move
  square.hpp             enum клеток
  transposition_table.*  таблица транспозиций
  zobrist.*              Zobrist hashing
  piece_square_tables.*  позиционные таблицы

apps/
  main.cpp               интерактивная игра
  selfplay.cpp           игра движка против самого себя
  speed-bench.cpp        benchmark

tests/
  test-*.cpp             Boost.Test тесты
```
