# Chess engine

Шахматный движок на C++14. Проект реализует представление позиции,
генерацию легальных ходов, оценочную функцию и поиск лучшего хода.

## Что реализовано

- представление шахматной позиции;
- чтение позиции из FEN;
- выполнение и откат ходов через `makeMove` / `undoMove`;
- генерация псевдолегальных и легальных ходов;
- рокировка, en passant и превращения пешек;
- проверка шаха, мата и пата.

## Поиск

Лучший ход ищется через `negamax` с alpha-beta отсечением. Для более стабильной
игры используется iterative deepening: движок постепенно углубляет поиск, запоминая лучший ход с последней полностью посчитанной глубины.

Также добавлен поиск по времени. Если передать ограничение времени, движок
вернет лучший найденный ход после истечения лимита.

Из оптимизаций поиска сейчас есть:

- move ordering;
- quiescence search;
- transposition table;
- Zobrist hashing;
- incremental Zobrist hash update;
- late move reductions;
- null move pruning;
- aspiration window в корневом поиске.

## Оценка позиции

Оценочная функция состоит из нескольких частей:

- материал;
- мобильность фигур;
- piece-square tables;
- пешечная структура;
- безопасность короля.

Оценка возвращается в сотых долях пешки. Например, `0.35` означает небольшой
перевес белых, а `-1.20` — перевес черных примерно на пешку с небольшим.

## Таблицы и структуры данных

Для таблицы транспозиций используется Zobrist hash позиции. Сама таблица
транспозиций хранит записи с ключом, глубиной, оценкой, типом оценки и лучшим
ходом.

Отдельно в проекте реализована собственная хеш-таблица Robin Hood hashing. Она
использует мой собственный Vector и сейчас применяется внутри transposition
table.

## Сборка и запуск

Собрать основной исполняемый файл:

```bash
make
```

Запустить интерактивную игру:

```bash
make run
```

Запустить тесты:

```bash
make test
```

Запустить benchmark:

```bash
make bench
```

Глубину можно передать через `ARGS`:

```bash
make bench ARGS=6
make selfplay ARGS=7
```
